# Item image prompts

Original images generated with Codex for this project.

All images use a hand-painted fantasy inventory-icon style matching the illustrated
metal and bronze interface. Each image contains one centred object, no text,
branding, frame or background. The generated transparent alpha is preserved when
downsampling to 128 x 128 pixels.

Common images are identical to their base image. Rare images retain the base shape
and outline, adding fine detail and nobler material; Epic images retain the same
shape and outline with a faint glow. Each quality variation uses its base as the
image-edit target. Quality frames are separate interface images.
