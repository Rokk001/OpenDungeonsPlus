# Painted feature icon sources

Original artwork generated with the built-in image generation tool on 2026-10-25 in the approved painted black-iron interface style. GPLv3+. The internal image model identifier was not exposed. Eighteen independent image calls; no procedural drawing, tinting or replacement motif.

Each selected source is 256x256 RGBA. Native generated squares were 1254x1254 and were only resampled with Pillow LANCZOS to 256x256, retaining their alpha. The four quality overlays retain grey, white, blue and purple identification and transparent centres (generated alpha residuals of at most 1/255 in the central area). No alpha thresholding or painting by script was applied. Existing item/potion/herb catalogue paintings remain unchanged.

Style reference: assets-src/gui/icons/tiles/TreasuryButton.png. ToiletButton additionally uses the existing ToiletButton tile as a functional silhouette reference. The other seventeen calls use only the style reference.
